# 🤖 EduBot – Intelligent Q&A Chatbot for Academic Assistance

EduBot is an AI-powered chatbot designed to help students get instant answers to academic questions using Natural Language Processing and deep learning. It serves as a virtual academic assistant, available 24/7 to support learning and problem-solving.

---

## 🌟 Features

- 💬 **Instant Q&A Chatbot** – Ask questions and get quick, accurate answers.
- 📚 **Subject-Specific Assistance** – Covers topics like Math, Science, Computer Science, and more.
- ⏰ **Available Anytime** – Study support whenever you need it.
- 🧠 **AI-Powered Responses** – Uses NLP and Gemini 1.5 for intelligent interaction.
- 🔐 **Clerk Authentication** – Secure user access and personalized sessions.
- 🖼️ **Image Summary Analyzer** – Upload an image (like handwritten notes or textbook pages), and the bot will generate a smart summary using AI!

---

## 🛠️ Tech Stack

- **Frontend**: React.js, Tailwind CSS, Clerk Authentication

- **AI Model**: Gemini 1.5 (for natural language understanding and response generation)
